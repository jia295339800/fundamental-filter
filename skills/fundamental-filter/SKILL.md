# 自主基本面研究与估值

接收证券名称或代码、明确问题及可选的选股理由、基准日、公告或报告。用户只调用本入口。先理解用户目标，再选研究方式；用户的明确任务优先于历史快筛优先级和当前估值吸引力。观察池变更由用户决定，技术择时留给用户的交易框架。

取证、经营判断与记录由Agent完成，用户不必填写参数或逐股审批。四种场景共享下述底层能力，不要求相同步骤：

| 用户目标 | 执行方式 |
| --- | --- |
| 明确完整研究、全面理解或估值 | 直接按[完整研究流程](references/workflow.md)执行，覆盖商业模式、经营驱动、财务风险、必要预测、资本与现金、选法、检查及价格判断；快筛不是前置许可，不能因高PE、低频或暂停结论提前收口 |
| 明确定向问题 | 聚焦指定问题和必要上下游证据，交付回答、条件、反证和未解决项；需要数字勾稽时使用同一共享检查，不强制整份企业估值报告 |
| 批量筛选 | 按[研究深度与复用](references/research-depth.md)快筛、自主分流，允许提前停止 |
| 未指定深度的开放性研究 | 按[研究深度与复用](references/research-depth.md)自主决定深度 |

从快筛点名升级深研，直接复用原件并检查时效，历史优先级没有否决权限。跨公司比较复用已有研究，对齐权益、日期和价值口径，不另建比较引擎。显式深研仍遵守硬排与证据边界：硬排不做普通估值/入池；准入或模型缺证时继续有边界的业务分析与必要补证，不伪称准入通过，也不强制目标价。定向任务可独立核实风险事实，结果不等同放行准入。

以下是完整研究及共享能力的执行骨架；定向任务只取解决问题所需部分。v0.6.1维护版在v0.6.0多场景架构上补齐必查披露正文与正式交付的衔接，保留v0.5.2数学与经济检查；本次仅提升覆盖与交付可靠性，不证明零漏检、预测更准或Token成本下降。

1. **锁定口径。** 解析代码和上市地，确定同一交易日的收盘价、财报截止日及币种。用户未指定日期时，用能核对到的最近交易日。按[内置准入 v1.6](references/policies/投研系统阶段1.1_市场范围与排除规则_v1.6_20261109.md)检查硬排、流动性与强化分流。明确点名且仅低于市值门槛的公司，核对用户实际成交需求后按 §1.3 单列。
2. **取证和复核。** 按[执行与复核卡](references/workflow.md)使用包内工具。正式准入、估值或入池前，运行 `entry.py disclosures extract`，实际阅读审计意见、政策及估计变更、重大及前期差错正文与对应规则，逐项复核并关联原有追溯事件。缺正文或适用状态未核时不得宣称准入已核实；手工证据路径通过 `entry.py formal` 交付，不能用旧计算脚本代替。批量初筛可标准入未完整核验，定向经营问题不强制全套准入。硬排即交付证据并停止该公司估值。缺准入证据记「待核」和具体补证项。核对追溯原因和比较金额后分流。复核主体、期间、重大差错、占用实质与公开监管证据。遇到已确认重大诚信事项，按内置规则 §2.3.2 核认定日期和现时影响。财报排雷写入复核卡，排雷结果作为复核线索交给 v1.6 裁定。
3. **复用与外部对照。** 准入后，识别会改变去留或模型的关键假设。按[外部研究与案例复用](references/research-learning.md)先读匹配案例，再按需用研报客和雪球找模型、分歧及反证。历史时点研究先用[历史检索闸门](references/historical-research.md)，使未审摘要留在取证端。会改判的数字先区分引述、推导和假设，再分别追原始来源、复算或做经营压力测试，记录采用、搁置和拒绝的理由。
4. **选方法与衔接经营。** 用[估值卡](references/valuation.md)按价值驱动建三情景。正常盈利可用轻量 PE，按估值卡声明真实利润口径与特殊损益的持续性假设，具备维持投入、税、资本成本和权益调整证据时用 EPV 校准。需要现金回收视角时加入独立六年路径。成长、周期、合同服务、资产折价使用各自驱动。按[估值校准](references/valuation-calibration.md)核对同范围的收入、成本费用、税、再投资和现金归属；已声明的算术关系默认检查，固定/变动费用、销售资本比及投资时滞只在证据适用时选用，不预设参数。不强制复杂DCF：有依据的历史或条件FCFF可直接输入，但不能仅凭数组和折现结果宣称高置信度。稳定期解释增长、再投资与资本回报，反推现价时列明固定了什么。强化审查的计算放「条件演算」，合理区间跨过现价时标明翻转条件。
5. **执行共享检查。** 已形成收入、成本、费用、利润或现金流表后，按[研究表接入](references/valuation.md#研究表接入共享检查)运行 `scripts/entry.py check`，核对输出再交付价格。自编分析脚本可以保留，将其中可检查的最终输入交给该入口，保存输入与检查结果；输入修改后重跑。缺证、不适用或工具不支持的块说明原因，不补造FCFF、ROIC或固定费用分解。矛盾先修正确定错误；未解决时按C交付，检查通过仅代表已声明关系勾稽。
6. **交付与续跑。** 按[观察池规则](references/policies/投研系统阶段1.2_观察池准入排序与退出标准_v1.0_20261028.md)给出去留。主表列基准价、A可用/B条件/C暂不可估、三情景、折溢价、到悲观值的下行、现价反推和改判条件。A由宿主复核关键经营锚点后判断，程序勾稽不证明预测准确；未来不确定但有边界时保留B，关系冲突或缺必要锚点时C不报价格。任务目录保存证据、假设、外部观点的实际影响和已复用材料。可迁移判断按[案例复用规则](references/research-learning.md#案例回写)写回项目，优先从已有证据续跑。

遇到战略演化、估值排序或深研申请，查看[基本面与估值政策](references/policies/投研系统阶段1.3_基本面与估值决策规则_v1.0_20261028.md)与[自主权限政策](references/policies/投研系统阶段1.4_Agent自主权限与人类审批边界_v1.0_20261028.md)。第三方方法出处记录在[来源说明](references/provenance.md)，全部运行逻辑随包交付。
