# 估值卡

估值卡通用字段为 `方法`、`截至日`、`财务期间`、`证据`、`口径`、`情景`。三情景键为悲观、中性、乐观，每项写 `依据`。金额单位是人民币亿元，股价是元，股数为股，比例用小数。港股等其他币种应先按同一汇率时点转换股价及对应报表金额，并记录原币和汇率。双重股本以同一权益范围比较。

| 方法 | 各情景的计算字段 | 选择依据 |
| --- | --- | --- |
| 成熟盈利 | 估值利润亿元、利润口径、PE；非经营及非经常项目 | 明确使用归母净利润、扣非归母利润或正常化可持续盈利，PE匹配该口径与持续性假设 |
| EPV | 正常EBIT亿元、正常折旧亿元、维持资本开支亿元、经营现金税亿元、维持营运资金增量亿元、WACC、超额与非经营资产亿元、实际融资债亿元、外部权益亿元 | 维持当前经营规模，把经营盈余资本化，再做归母权益桥 |
| DCF | 见[估值校准](valuation-calibration.md#dcf) | 现金路径、稳定期、资本成本和归母权益桥有依据时，校验价格隐含要求与终值敏感性 |
| 成长 | 存量利润亿元、存量PE、新增利润亿元、新增PE | 拆存量盈利与增量生命周期。保留再投资、渗透率、利润兑现、竞争衰减和最强反证 |
| 周期 | 销量百万、售价元、核心收入占比、扣非归母利润率、PE | 从量价、成本和盈利中枢做情景，核低谷偿债及再融资 |
| 合同服务 | 收入亿元、归母利润率、现金兑现率、现金倍数 | 区分续约、新签转收入与回款，匹配合同和结算责任 |
| 资产折价 | 应收折价率、存货折价率，可选新增处置费用亿元 | 用可变现净资产压力测试，说明持有层级、资产受限、周转需求、资金烧损和兑现路径 |

成熟盈利各情景给`估值利润亿元`及`利润口径`，后者选`归母净利润`、`扣非归母利润`或`正常化可持续盈利`；均对应同一普通股归母权益范围，三情景口径一致。旧`正常化利润亿元`保留为数值别名，缺声明时只算“口径未声明”的B条件值，字段名不证明扣非或正常化；新旧数值并填须一致。

`非经营及非经常项目`逐项给`项目`、`持续性假设`、`估值处理`及有则引用的`证据`，说明投资收益、补助、减值等为何保留/剔除/折减，以及在预测期或长期可否重复。没有相关项目时明确给空数组，而非把漏填视为不存在。非经营不等于非经常，不能机械删除全部投资收益；扣非也不自动等于可持续。声明`正常化可持续盈利`时另给`正常化调整说明`，从可核利润追踪调整与税、少数权益，避免把未经调整的归母利润改名。PE依据应解释为何适合实际利润口径和风险，持续性缺证保留条件判断，不自动升A。程序记录声明及缺口，不代替事实核验或判断应如何调整。

资产折价在卡的 `资产输入` 给出 A股股数、B股股数、流动资产亿元、全部负债亿元、少数股东权益代理亿元、净应收亿元、净存货亿元。如有 B 股，再填 B股价格、每单位B股币种折人民币。单上市证券用全部股数及 B 股数 0；港股经汇率换算后可沿用单股类计算字段，输出须注明原股份类别。净额折价从扣过会计减值的账面金额出发，少数权益以能核实的归属优先，采用账面代理时明示限度。经营价值与资产兑现价值独立列示。

EPV 的正常折旧加回与维持投入配对，经营现金税与经营利润范围一致。融资债与税、租赁和资本成本统一口径，经营必须保留的资金计入营运需求，超额现金归母桥按可归属余额处理。关键参数缺证留待核，现有轻量估值可保留。资产再生产价值回答重建成本，作为独立研究时另行列示。六年现金回收可在成熟盈利、合同服务或 EPV 卡加入 `六年现金回收`，包含期初可归属超额现金亿元、六年归母可分配现金亿元数组、依据、证据。保留负年份，输出名义累计覆盖和缺口。资本化价值和现金回收覆盖分别比较。

程序用中性倍数或资本成本反推现价需要的正常利润、增量利润、现金兑现率或额外归属资产价值。条件演算和已通过准入的轻量估值分列。参考值精度服从证据质量，结果带现价时点、报告期、情景成立条件和下一条核验触发。

v0.5.2新增可选的情景`经济关系`，输入及A/B/C口径见[通用经济关系](valuation-calibration.md#通用经济关系默认核对与可选建模)。旧计算字段继续支持；默认B条件值，显式经济矛盾转C并隐藏价格。计算可从经营桥导出FCFF，或保留有依据的直接FCFF。等级与准入路由独立，A需宿主复核关键锚点，不能以程序执行成功代替证据充分。

正式交付由包内 `entry.py formal` 接收已经过宿主复核且附必查正文覆盖的结构化 JSON；覆盖格式见[执行与复核卡](workflow.md#必查披露正文覆盖)。`calculate.py`保留为历史数值复算，不代表新任务准入放行。顶层给 `证券`、`行情时点`、`准入`、`基准收盘元`、`总股数`，以及可选的 `估值卡`、`排雷底稿`。通过准入或允许条件演算时需给 `准入依据` 原文引用列表，基准和财务期间与证据一致。脚本验证字段、时点和算术，原文事实与适用规则仍须逐项复核。

## 研究表接入共享检查

形成经营表之后、撰写最终估值之前执行。准入待核时也能单独核算术；结果不放行准入、不提供正式价格。已有完整估值卡直接交给入口；自编脚本可导出同一个JSON，不必重建DCF。

```sh
python3 -B /path/to/fundamental-filter/scripts/entry.py check /path/to/research.json > /path/to/check.json
```

`research.json`可以是估值卡本身，也可以是含`估值卡`的现有JSON。尚未选估值方法时用`方法:研究检查`；真实估值沿用原来的方法。给出`截至日`、`财务期间`、`依据`、`证据`，以及`研究口径:{币种:CNY,金额单位:亿元,范围:合并经营}`。研究卡只核已声明关系，原件事实和历史时点仍走既有取证/历史闸门。

各`情景`保留原估值字段，可直接追加`经营预测`数组。行中用`收入亿元`、`营业成本亿元`或`毛利率`、`EBIT亿元`，费用直接写`销售费用亿元`、`管理费用亿元`、`研发费用亿元`、`税金及附加亿元`和有则填写的`其他经营费用亿元`；也可沿用原生`费用`数组及有证据的固定/变动分解，两种费用写法选一种。直接金额仅代表该期金额，不推断固定费用性质。纳入同口径EBIT的全部成本费用；无费用时显式给`费用:[]`并说明依据。遗漏或改名的真实项目仍需研究者识别，程序不读取财报自动补项。

可用的`现金流桥`、`增长约束`、`项目投入`、`价值归属`、DCF的`直接现金依据`和`稳定期`按[原生输入](valuation-calibration.md#可重算的经济关系输入)原样追加；也可以继续写在`经济关系`，同一块只存一份。适配只继承已填口径、依据和证据，数值由研究输出，不提供预测参数默认值。

未做的块在相应情景的`未检查`中按块名给`{类型:缺证/不适用/工具不支持,说明:具体原因}`。例如只估PE且缺维护投入、融资归属时，现金桥标缺证，稳定期标不适用；保留CFO诊断，不能改名成FCFF。未说明的块会如实回显，不能称全部通过。

读取`经济关系检查`与`覆盖`：发现确定矛盾先回到原表修正，保留初次结果与修正依据；未解决时不报有效价格。报告关联原输入`输入SHA256`，数值变化后重跑。最终用同一张卡经`entry.py formal`或批次复核入口交付；底层`models.value`与`calculate.py`继续复用此适配和共享检查，正式入口另核披露覆盖。准入待核或硬排仍由原路由停止正式估值；本入口不改变准入规则。
