# 外部研究与案例复用

## 复用

完成准入后，在用户指定的项目根或当前工作目录及其父目录寻找 `04_研究经验/索引.md`。只使用一个明确属于本任务的经验库。从索引按证券代码、业务模式和产业链节点筛选，优先读取同公司的未兑现假设，其次读取最相关的一两条同类案例。遇到混合业务先按最影响价值的分部匹配。无可用经验库时用当前任务底稿交付。

区分可复用的模型结构、需要重核的公司参数和有时效的行情。对新公司优先沿用问题、对照口径和反证路径。利润率、倍数、产能利用率、周期位置等须由目标公司的同期证据校准。旧公司原件主体与期间仍有效时可免重复下载，同行案例可以省去重复筛选指标。结果中注明用了什么、节省了哪一步、哪项需要重核。

## 外部对照

先写一条会改变去留、方法或区间的假设，以及什么证据会推翻它。没有这类问题，或已有可靠原件足够定案时直接收口。硬排仍按准入流程立即停止，关键准入证据不足先待核。

- **研报客。** 需要行业链条、同行或经营预测时，优先使用已装的 `yanbaoke-research-report-download` 的只读检索，限制结果和报告日期。用证券代码、简称或细分环节检索。简称零结果换代码，行业问题从行业深度报告找上下游、利润来源和候选企业。选能说明变量或模型的报告。仅在已获相应授权时使用付费下载。
- **雪球。** 需要不同拆分、逆向判断或行业一线线索时，按证券代码或业务名加关键变量查公开文章。优先用宿主已配置的公开检索渠道，如 Agent Reach。只读可达内容。只有摘要或链接时标明可见范围，参数须另有出处才能入模。
- **收口。** 默认先选一至两篇通过时效筛选的研报和一条有实质差异的公开讨论。能改判的分歧才追加。工具不可用或同义改查仍无结果时记录覆盖，回到公开原件继续。外部观点的缺席本身不构成准入缺口。

### 时效筛选

历史回测、历史时点估值和已知答案开发案例，外部搜索从[历史检索闸门](historical-research.md)进入。该入口先截住供应端正文，研究上下文只接收经过日期筛选的候选元数据；正文需核原始发表日、具体版本和SHA256后放行。不能先把搜索摘要或整页返回读入上下文再过滤。实时研究不受这一历史模式限制。

记录原始发布日期、可见修订日和文中实际数据期。研报客上传日、雪球转载或编辑日不能替代原始发布日期。历史复盘只引用基准时点前已可获得的版本。若同日先后无法核实，仅保留线索。跨过基准时点的修订仅在能核到当时版本时使用。

优先选基准日前、覆盖最新有效定期报告或重大经营变化的材料。核对其后是否发生重组并表、产能或政策变化、景气切换、估值环境变化等足以使假设失效的事件。近期文章也可能引用陈旧数据。较早材料、日期不明或已跨关键事件的观点，只作行业结构、历史对照或待核线索。其利润率、预测、可比倍数和目标价等数值经当期证据重新验证才可引用为当前输入。跨周期用旧数据时标注周期位置和用途。

### 引用与核验

按数字逐项核对会改变去留、方法或估值区间的输入。同一篇文章可能混用以下来源。

| 外部数字 | 核验动作 |
| --- | --- |
| 转引研报 | 找到原报告及相关页表。区分研报转引的已披露数据和分析师预测，前者追到公告、财报或原统计发布方，后者列为外部假设。 |
| 公开行情或行业数据 | 追到行情源或原统计表，核对主体、报告期或交易时点、单位、币种和统计范围。价格、市值和倍数核对复权、股本、股类和盈利口径。 |
| 作者推导 | 保留公式及各项输入，先对齐口径再复算。判断证据能否推出结论，特别核查分母、年化、重复计值和归属。流水、订单、预收、收入、利润和可分配现金之间需要明确转换依据。 |
| 作者业务假设 | 写明成立需要的量、价、利润率、产能、成本或回款条件。与公司实际、同口径同行及相似历史阶段比较，列出反证。用合理上下界检验能否改变去留。 |

记录作者或机构、日期和数据期、所见范围、出处与页表、原文数值和口径、核验结果及对模型的影响。按原始披露或数据生产者去重。已核对的事实进入事实输入，能复算的推导保留公式，合理的假设标明条件后进入情景。原文拿不到、引用逻辑不成立或无法复算时，保留为线索或拒用。关键输入缺证时列出待核项、反推条件和下一处可核披露。评级和目标价只作观点记录。

## 案例回写

将会改变下一次研究动作的内容写入项目经验库。已有公司或行业卡时追加带日期的观察和兑现记录，保留原预测及当时的信息边界。新案例在 `04_研究经验/索引.md` 留一行，便于按证券、业务和产业节点查找。完整证据和模型留在原任务底稿。

每条案例最少保存以下内容。

- 截至日、证券、业务或产业节点、底稿链接。
- 一条关键判断、模型里的参数或范围、翻转条件、支持与反面证据。
- 哪条外部观点被采用、搁置或拒绝，为什么。
- 状态为待验证、已验证或已证伪。待验证项写下一份报告、指标或明确事件。

有新财报或披露时按原口径对照实际，保留预测误差和失败案例。单例可以指导下一次核验。经过同类公司或跨期对照且复核反例后，才提议升级成行业默认检查项，记录适用范围和失效条件。涉及准入或用户已确认的规则时按包内审批边界处理。
