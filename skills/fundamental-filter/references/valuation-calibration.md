# 估值校准

在轻量估值可能改变去留时，选一项最能验证主假设的校准。沿用已确认的基准日、准入及盈利口径。记录基线、校准后结论、令结论翻转的经营条件和下一处可核披露。

## 利润转现金

按可比期间列扣非归母、合并经营现金、购建支出、营运资金变动、租赁和并购付现。利润与合并现金的归属口径分开。将必要维持投入与增长投入按可核证据拆分；并购、新项目及偶发收款单列。经营现金减购建支出可诊断兑现压力。估算可持续现金时另核经营现金税、归属、融资、资本开支和营运需求。

## 周期中枢

先选覆盖量价和原料价差不同阶段的历史证据，记录销量、售价、原料或单位成本代理、产能和利润率。用当前可持续产能和可比周期阶段估算正常化利润。低谷单独查现金覆盖、到期负债和再融资。历史样本仅覆盖部分阶段时，标为历史压力检验，写明缺少哪一段。若依靠产能、产品或地区结构变化才能达到现价所需利润率，写出对应的价差或产能利用率条件。

## 分部桥接

分别列经常性税后归属收益、一次性项目未来净现金和新增业务。只有收入或税前分部数时，先核税、少数权益、公司层成本与内部抵销。预收款按履约与资金用途核对；经营价值和股权桥之间逐项核掉重复的现金、债务与资产。关键利润或剩余投入无据时，用明确的占位条件反推，估值留待核。

## DCF

在经营现金路径、资本投入、终值和股权桥具备原文及可重算依据时，用 DCF 校准。写出分阶段量价或收入、利润率、税、再投资和营运资金。FCFF（企业自由现金流）用税后经营利润加折旧摊销、减资本支出和经营营运资金增量，保持利息、租赁及实际融资债的口径一致。权益桥从经营价值加可归属的超额或非经营资产，扣融资债和外部权益。合并口径的「经营现金流减购建支出」只作为诊断代理。

估值卡方法填 `DCF`。每种情景填以下字段，金额为人民币亿元。

- `显性期逐年FCFF亿元` 从下一年起依次列示，保留负年份。三情景使用同一显性期。
- `永续首年FCFF亿元` 填显性期后第一年可持续的正现金流。解释现金、再投入和增长的关系。
- `WACC` 和 `永续增长率` 填小数，要求 WACC 大于永续增长率。用当期证据或注明依据的区间。
- `超额与非经营资产亿元`、`实际融资债亿元`、`外部权益亿元` 填非负金额。零也须说明依据。

输出显性期、终值现值、终值占经营价值比例和权益桥。另固定中性显性期现金和资本成本，反推现价所需的永续首年现金；保留固定的永续增长率，把现金要求换成可核的收入、利润率或再投入条件。固定其他输入分别检查折现率和永续增长率，报告结论翻转的条件。终值主导且无法由经营证据支持时，保留可证实的轻量结论或待核状态。现价反推解释模型下需要成立的条件。

## 通用经济关系：默认核对与可选建模

所有方法先确认产品/分部、期间、币种和经济归属一致。机器仅检查输入中已声明的关系和来源接口，不自动读取原件判真，也不把缺少某种模型当作企业硬排。硬排与准入待核仍先于估值。

已知算术关系默认检查：收入减成本和费用等于经营利润；利润、税、净再投资到现金；稳定增长、再投资与回报的联立；同一经济项目的重复计值。检查发现矛盾时保持准入结论，输出C及冲突，不继续展示失效价格。字段格式、非有限数值或无效DCF分母等沿用输入错误接口，CLI退出2。

经营预测方法均为可选：

- 收入变化时，有依据才拆固定支出、收入比例支出与阶段投入；不能无依据保持费用率，也不能假设固定支出永远不变。毛利率还要解释产品组合、售价、单位成本和经营杠杆。删研发/推广的成本改善与未来收入相容。
- 盈利与资本回报稳定时可检查`增长≈再投资率×增量ROIC`；既有资产效率、价格或利润率变化时，这不是完整增长公式。平均历史ROIC不能自动代替新增回报。
- 可用`新增收入/增量销售资本比`估总净再投资，已经包含营运资金，不再叠扣一次。收入收缩不自动产生可收回资本。项目爬坡单列投入与收益期，旧投入不在未来重扣。
- FCFF按EBIT减经营现金税，再减总净再投资并处理其他经营非现金调整；FCFE按同范围净利润减净再投资、加净举债。两者不能混用折现率。利润和现金若涉及合并/归母、利息、研发、租赁及参股，先解释转换；少数权益不能省略。
- 研发经济资本化需同时改利润、资本和再投资，保持真实现金税；单纯重分类不能创造现金。已入账租赁不重复资本化。维护与增长支出需配合对应收益，不能机械用折旧当维护，也不能保留增长而加回全部增长支出。

零增长、有限寿命、衰退、清算和战略机会仍可选择适用轻量方法。不要把所有业务都塞进稳定增长DCF或把所有不确定性归为不可估。

## 可重算的经济关系输入

沿用旧卡和旧情景字段。在各情景中可选填`经济关系`。完整教学卡见[economic-example.json](economic-example.json)，通过现有`calculate.py`运行；里面的数值是合成条件，不是预测参数。

`经济关系`公共字段：`币种:CNY`、`金额单位:亿元`、`范围`、`依据`、`证据`。外币先按同一基准转换。每条经营预测、现金桥、增长约束和项目记录附`依据`与`证据`，区分披露、推导和未来假设；引用要能定位到支持对应参数的原件。入口沿用原来的来源校验，新增嵌套引用也过同一个接口，不另建历史检索入口。

| 可选块 | 输入与运算 |
|---|---|
| `经营预测` | 按下一期起顺序列数组：`收入亿元`，以及`营业成本亿元`或`毛利率`。费用数组各项为`名称`、可选`固定亿元`、`收入比例`、`阶段亿元`。可填`合计亿元`和`EBIT亿元`作勾稽；未列的费用视为模型声明的零，宿主仍须核遗漏 |
| `现金流桥` | 与经营预测同顺序、同期间。`现金流类型:FCFF`时给`EBIT亿元`（可由经营预测导出）、`经营现金税亿元`；FCFE给`净利润亿元`、`净举债亿元`。再投资可直接给`净再投资亿元`，或完整给`资本开支亿元`、`折旧摊销亿元`、`营运资金增量亿元`；两套并填只勾稽，不重复扣。可加`其他经营非现金调整亿元`，其组成需追溯 |
| FCFF/FCFE融资桥 | 可给`税后利息亿元`及`净举债亿元`勾稽FCFE；FCFE若用于企业DCF，必须借这两项转回FCFF。直接FCFE数组不能交给WACC折现 |
| `直接现金依据` | 不建完整经营桥时给`现金流类型:FCFF`、`依据`、`证据`、`再投资处理`，说明历史/合同/条件现金如何扣维持及增长投入；显性FCFF数组仍按旧字段输入。证据少只能支持条件值，不能伪装A |
| `增长约束` | 数组。`类型:稳定回报`给`再投资率`、`增量ROIC`，可给`利润增长率`；只有显式声明`既有资产效率不变:true`才作严格等式检查。`类型:收入资本`给同范围净`新增收入亿元`、`增量销售资本比`，可给净再投资；可用`期`把同期约束连到现金桥（从1开始）。有经营路径时与前一期收入核对，首期可给`基期收入亿元`；有时滞不要强连同一期 |
| `项目投入` | 数组，给`投入期`、`收益期`、`投入亿元`。0期指已发生投入；正期为显性期序号。存在现金桥时用`投入科目:资本开支亿元`或`净再投资亿元`绑定同一期，检查该科目覆盖所有已分配项目。收益可以晚于显性期，但不能早于投入。适用范围及投入科目要由宿主核对，不能把净额释放和项目支出混为一谈 |
| `价值归属` | 用`项目`+`范围`识别同一经济资产/索偿，`位置`为经营现金、超额与非经营资产、融资债或外部权益。同一项目不能在多处计值。若优先索偿声明`须从企业价值扣除:true`，不能又在企业现金内扣。不同命名、未申报项目、合并抵销和真实持股仍需人工复核 |

经济DCF可以省略原显性FCFF数组，由现金桥生成；也可以同时填数组并核一致。非DCF仍可用上述经营与现金诊断，不要求改变原来的估值方法或补全所有块。旧卡未列经济来源时数学结果保持兼容，并标为B类未经完整来源检查的条件计算。

经营与现金记录默认继承公共币种、单位和范围；记录另声明时必须一致。可用`期`标明从1开始的序号，不得错位。FCFE若同时有经营路径、经营税和税后利息，核净利润与EBIT的桥接；缺这一连接时不凭融资换算升A。财报归母利润含其他收益等情形应先重构同范围盈利，不硬拼到合并经营EBIT。

## 稳定期与现价反推

经济DCF的`稳定期`给`依据`、`证据`。有可持续经营锚点时，填**显性期之后第一年**的`税后经营利润亿元`与`增量ROIC`，以情景已有的g算再投资率和FCFF。可选填`再投资率`及原`永续首年FCFF亿元`核对；不等于最后一期高投入FCFF机械增长。稳定ROC高于WACC时解释`超额回报依据`，不强制ROIC=WACC。

若直接采用有依据的稳定FCFF，保留旧终值字段，写`再投资与增长说明`，不强制虚构ROIC。稳定现金正、g<WACC只是数学条件，长期增长还应与经济规模、竞争、币种通胀和所需投资一致。没有概率依据时不对三情景平均赋权。五年路径不默认永续重复；有限寿命或清算另选适用方法，不强造永续现金。

已有价格反推保留。提供稳定NOPAT与ROIC时，新增反推现价所需的NOPAT；再给`收入亿元`和`经营现金税率`时，可换算所需营业利润率。若同时给`营业利润率`，先核三者与NOPAT的等式。上述反推固定中性显性现金、WACC、g、ROIC、股权桥，再固定收入和税；改变任一条件就要重算。同一价格有多组合理经营解释，不能说反推出唯一市场预测。

## A/B/C 与研究输出

默认B。`估值等级:A`需卡内`等级依据`：`关键经营与估值锚点已复核:true`、`依据`、`证据`；仍受经济关系缺口约束，不能凭声明或精细数字自动升级。A表示宿主对锚点与情景的研究判断，不是机器事实认证、概率置信区间或收益保证。

宿主指执行此Skill的Agent。由Agent自主取证、选法、复核和填卡；这些来源字段和等级声明不要求用户提供会计参数，也不新增逐股人工审批。

未来有不确定性但锚点足够、条件明确，保留B。直接FCFF、轻量PE、条件反推均允许。关系矛盾或宿主判断连必要边界都无法建立时C；可填`估值等级:C`与`不可估原因`，不报价格。C与企业准入硬排分开，补足关键证据可重评。

最终解释值得花注意力的逻辑、现价押注、最强反证和改变去留的门槛。经济检查通过不等于预测方法有效；固定/变动费用模型、资本效率和经营情景的准确度仍待新样本对照，不设行业利润率、ROIC、寿命或折现率默认值。
