# 投研系统阶段 1.2：观察池准入、排序与退出标准 v1.0

- **版本日期：** 2026-10-28
- **状态：** 已验收；正式规则
- **本次发布：** 用户于 2026-10-28 确认接受草案；发布正式规则 v1.0，固化观察池准入/退出、可解释排序、三级估值、估值快照和人机协作边界。
- **所属阶段：** 阶段 1——投资决策规则
- **前置依赖：** 阶段 0 章程 v1.0、阶段 1.1 市场范围与排除规则 v1.0
- **本文件用途：** 定义企业如何进入基本面观察池、如何根据估值与市场预期排序、何时升级研究、何时降级或退出。此文件只制定决策规则，不代替后续阶段的具体财务分析、估值模型和 Agent SOP。

## 1. 设计目标

观察池不是“好公司名单”，也不是买入名单。它应帮助用户回答：

1. 当前价格相对于企业合理价值是否存在明显折价？
2. 当前股价/市值隐含了怎样的经营预期，这些预期是否合理？
3. 若判断错误，悲观情景下的损失和生存风险有多大？
4. 估值判断的证据和假设有多可靠？
5. 哪些企业值得优先投入进一步研究资源，哪些只需等待价格、业绩或行业条件变化？
6. 研究过程中是否发现了值得另行研究的上下游、关键配套或相邻产业链环节？

核心原则：**低估程度是研究排序的重要主轴，但不能把表面低估等同于真实机会。** 估值折价必须与下行风险、估值可信度、财务/治理风险及关键假设的可验证性一起判断。

## 2. 必须区分的三个结果

每次研究应分别输出三个维度，不能混成一个“保留/剔除”标签：

### 2.1 估值吸引力（当前机会判断）

判断当前价格是否相对于合理价值有吸引力，主要依据：
- 悲观、中性、乐观情景下的股权价值或每股价值区间；
- 当前股价、市值及其数据日期；
- 中性情景下的折价/溢价；
- 悲观情景下的潜在下行与资本损失风险；
- 当前价格隐含的收入增长、利润率、盈利水平、周期位置、资本回报等关键预期；
- 估值结论的置信度和对关键假设的敏感程度。

### 2.2 进一步研究优先级（研究资源分配）

研究优先级不完全等于估值吸引力。存在较大潜在低估、但有一个可通过进一步研究解决的关键不确定性时，可能应优先研究；若低估判断依赖无法验证的假设，则不能直接列为高确信机会。

排序应综合考虑：
1. **潜在低估幅度与市场预期差异**：中性价值相对当前股权市值的折价是主要排序依据。
2. **悲观情景与下行风险**：识别可能的永久性资本损失、融资/偿债压力、业务恶化和估值下修风险。
3. **估值可信度**：原始资料质量、盈利可预测性、关键假设证据、模型对少数参数的敏感程度。
4. **基本面与财务/治理稳健性**：判断低估是否可能是价值陷阱；已由阶段 1.1 触发的特殊风险按相应流程处理。
5. **不确定性是否值得花资源解决**：如果一项有限的研究能够显著改变结论，研究优先级可提高；如果关键未知无法验证或研究成本过高，则记录未知并降级，不无限扩展。
6. **催化剂与验证条件**：记录可能使价值差异被市场识别的事件、数据或经营节点；不要求每家公司必须存在短期催化剂，也不预设固定持有期限。

不得只按“中性估值比市值高多少”机械排序，也不得只因公司质量好就忽略明显高估。

### 2.3 观察池状态（后续如何跟踪）

状态是管理任务的辅助字段，不是研究结论本身。建议采用：
- **优先深研：** 有较大潜在估值差异，且进一步研究可能显著提高/降低判断可信度。
- **高优先级关注：** 折价有较充分证据支持，悲观情景风险可理解，估值可信度达到可用水平。
- **条件观察：** 可能低估，但需等待关键数据、行业条件、盈利拐点、融资安排或风险事项得到验证。
- **价格/业绩触发观察：** 企业质地或长期价值值得保留，但当前估值吸引力不足；记录何种价格、业绩或预期变化后重评。
- **低优先级/暂不跟踪：** 估值吸引力不足、潜在回报风险不佳、研究价值有限，或核心假设缺乏支持。
- **特殊风险队列：** 依据阶段 1.1 只能进行风险识别或强化审查的企业，不与普通企业直接混排。
- **资料不足、无法可靠估值：** 不是低优先级结论，而是明确列出关键缺口；补充资料后再判断。

如公司被阶段 1.1 硬性排除，原则上不进入常规观察池；用户明确点名要求研究的例外按授权处理，并记录豁免范围。用户可以手动提高或降低某家企业的研究优先级，但 Agent 必须保留用户覆盖自动排序的原因和日期。

## 3. 估值深度分层：在效率与可靠性之间取得平衡

**核心原则：每家常规候选企业都应尝试形成与现有证据相匹配的估值判断，但不要求初筛阶段完成三套完整财务预测。** 初筛的目标是识别潜在低估、明显高估、风险陷阱和需要进一步核验的对象，不是一次性把企业研究透彻。

采用三级估值深度。三级是资源投入层级，不是每家公司必须依次通过的固定关卡。

### 3.1 第一级：估值分诊（所有通过范围筛选的常规候选企业）

目标：以较低成本判断是否存在值得继续研究的估值线索。

最低工作要求：
- 识别商业模式、行业类型及适用的初步估值方法；优先复用已有行业/公司底稿和可靠的二手研究地图。
- 获取当前股价、市值、最新可用财报与关键经营指标；区分市场数据时间、财报报告期和分析时间。
- 选择少量最影响价值的变量，通常先聚焦约 1–3 个核心驱动因素；不得为了完整而展开无关行业支线。
- 在资料允许时，给出悲观/中性/乐观的粗粒度合理价值区间或估值方向。可用宽区间、情景边界或相对估值交叉检查，不要求此阶段建立详细的三套损益表、资产负债表和现金流预测。
- 初步判断当前价格隐含预期是否苛刻、是否存在潜在折价，以及最需要核验的关键假设。
- 记录估值吸引力、研究优先级建议、置信度、主要风险和下一步触发条件。

第一级必须交付“有证据支撑的初步判断”，而不是必须交付一个看似精确的目标价。如果现有资料不足以形成有意义的价值区间，允许输出“暂无法可靠估值”，同时说明缺少什么、它为何重要、是否值得补充研究。不得用随意套用的 PE/PB 倍数、无来源预测或精确到小数点的目标价伪装成准确估值。

### 3.2 第二级：校准估值（有潜在折价、重大分歧或关键疑点值得验证的企业）

目标：判断初筛中的折价是真实机会，还是数据、盈利质量、周期位置或估值方法造成的假象。

- 阅读与结论相关的财报期间，核验利润、现金流、负债、资本开支及其他关键数据；不要求无差别通读所有历史资料。
- 研究最可能改变估值的行业变量、公司竞争位置和关键经营驱动。
- 选择真正可比的同行，校验估值口径与盈利质量。
- 明确悲观/中性/乐观情景的核心假设，更新价值区间与当前价格隐含预期。
- 对关键假设进行初步敏感性分析，并列出仍未解决的高影响问题。

升级到第二级时，Agent 必须说明：为什么值得花更多资源、要验证的具体问题、预计可获得的决策价值、所需资料/工作量及停止条件。

### 3.3 第三级：深度估值（少数高价值候选企业）

目标：为高优先级候选形成更完整、可审查的价值判断。

根据商业模式需要，建立更完整的收入、利润率、资本开支、现金流、资产负债、产能/周期或分部业务预测；开展敏感性分析、反向估值、压力测试和永久性资本损失分析。仅当这些工作可能实质改变研究优先级或投资判断时才展开，不以“研究得越多越好”为目标。

### 3.4 升级、降级与停止规则

- 初筛显示潜在折价大且有可验证的关键疑问：优先考虑升级到校准估值，而不是直接认定为高确信机会。
- 初筛显示折价较小、风险回报不佳，且没有足以改变结论的新问题：降级或停止，不为完成三情景形式而继续研究。
- 估值高度依赖无法验证的假设：降低置信度并明确标记，不以更复杂模型掩盖证据缺口。
- 遇到多个可能影响结论的研究方向：先提交少量选项、理由、证据、成本和潜在决策价值，等待用户收敛范围；不得自行把所有方向研究完。
- 如果某项研究不能合理改变估值、风险判断或观察池状态，应停止该分支并记录原因。

### 3.5 三情景的最低要求与禁止事项

对常规候选企业，系统应“尽力尝试”给出悲观/中性/乐观估值或合理价值区间，但三情景的细化程度必须与研究阶段匹配：
- 估值分诊：粗粒度区间/情景边界即可，假设数量应尽量少且可解释。
- 校准估值：围绕关键变量形成有证据支撑的情景，并核验财务与行业假设。
- 深度估值：对高优先级企业建立更完整的预测、敏感性和压力测试。
- 如无法可靠估值，必须明确写出“暂无法可靠估值”、具体缺口、可能影响及是否建议升级；不得强行补齐数字。

比较口径必须一致：
- 股权价值模型与当前股权市值比较；企业价值（EV）模型须合理扣除净债务、少数股东权益等并转换为股权价值后，再与市值比较。
- 计算每股价值时，应考虑稀释股数、可转债/期权等潜在稀释因素（如重大）。
- A 股与港股需明确币种、价格/市值数据日期和必要的汇率口径。
- 周期型企业不得机械外推景气高点利润，应考虑正常化盈利和周期位置。
- 对债务违约、重大逾期或流动性危机企业，按阶段 1.1 进入风险识别级初筛，不使用普通持续经营企业估值模型。

### 3.6 估值吸引力的时间戳与数据快照

每次形成或更新估值吸引力判断时，必须保存独立、不可被新记录覆盖的评估快照，至少包含：
- **分析时间戳：** ISO 8601 格式，使用 `Asia/Shanghai` 时区；港股与 A 股均以该时区记录，便于统一排序和复盘。
- **市场数据时点：** 股价、总市值/流通市值、成交数据所对应的交易日/时间；如非实时数据，明确标注。
- **财务数据时点：** 最近使用的财报报告期、公告日期及数据来源。
- **估值记录：** 悲观/中性/乐观区间或暂无法可靠估值的原因、关键假设、估值方法、置信度、当前价格隐含预期和研究优先级。
- **版本与变化：** 估值方法/模型版本、相较上一次记录的结论变化及触发原因。

分析时间戳不得替代行情数据日期或财报报告期。若市场数据滞后或关键数据无法核实，必须单独标记；后续更新应新增快照，不覆盖历史估值记录。

## 4. 估值与市场预期的标准化输出

每家企业至少输出：
1. 估值吸引力分析时间戳（ISO 8601、Asia/Shanghai）、市场行情时点、最近财报报告期及公告日期；每次更新新增记录，不覆盖历史快照。
2. 当前股价、总市值/流通市值（按适用口径）、数据日期。
3. 悲观/中性/乐观估值区间或价值结果；若尚无法可靠估值，须明确记录原因。
4. 中性情景相对当前价格/市值的折价或溢价。
5. 悲观情景下的潜在下行，以及风险是否可能导致永久性资本损失。
6. 乐观情景下的潜在上行，但不得只以乐观情景作为排序依据。
7. 当前价格隐含的关键经营预期，以及这些预期相对行业和公司历史表现是否苛刻/保守。
8. 最影响估值的 1–5 个假设及其证据强度，数量与研究阶段匹配。
9. 估值置信度：高/中/低，并解释原因；置信度不得仅由 AI 主观给出，须关联数据完整性、业务可预测性和假设敏感度。
10. 估值吸引力判断、进一步研究优先级、观察池状态及其理由。
11. 下一次复核的触发条件，以及如有必要的跨产业链机会提示。

## 5. 研究排序规则

### 5.1 规则式排序优先于未经校准的精确分数

初版不直接采用看似精确的综合分数或固定百分比权重。先用统一维度和规则形成可解释排序，避免把未经测试的主观权重包装成数学精确性。阶段 7 可用真实案例检验是否有必要引入数值评分。

批量排序建议按以下顺序判断：
1. 先执行阶段 1.1 的范围、硬性排除和特殊风险路由。
2. 对常规候选比较中性估值折价及当前价格隐含预期。
3. 检查悲观情景损失、财务/治理风险与潜在永久损失。
4. 比较估值可信度及低估判断对关键假设的依赖程度。
5. 判断是否存在可以用有限研究解决的关键不确定性。
6. 综合上述信息，给出优先级和排序理由；对证据不足者明确标记“暂不可可靠排序”，而不是强行排名。

### 5.2 低估幅度如何影响优先级

- **折价越大，原则上越值得优先关注**，前提是折价不是由错误数据、不可持续盈利、结构性衰退或重大风险造成。
- 中性估值显示低估，但悲观情景损失巨大、估值置信度低的企业，不能仅凭折价幅度列为最高确信机会；可进入“优先深研”以解决关键疑问，或进入“特殊风险队列”。
- 中性估值接近当前价格、但企业质量良好的公司，可以作为“价格/业绩触发观察”，但不应挤占明显低估企业的研究资源。
- 中性估值低于当前价格、且市场隐含预期苛刻的企业，通常降低优先级；若悲观情景风险极高，应明确说明，而不是仅以一个低目标价值作结论。
- 对不同商业模式使用适当估值方法，不可直接比较未经调整的 PE、PB、EV/EBITDA 等单一倍数。

## 6. 准入、升级、降级与退出

### 6.1 进入常规观察池

同时满足：
- 符合阶段 1.1 市场范围与准入规则；
- 能建立至少初步可信的行业/公司价值驱动解释；
- 有与资料质量相匹配的估值区间或明确记录为什么无法估值；
- 能说明当前价格隐含预期、主要风险和下一步验证事项；
- 存在明确的关注理由：估值差异、潜在经营变化、可验证的关键不确定性，或值得等待的价格/业绩条件。

进入观察池不代表建议买入，也不要求立即交易。

### 6.2 升级为优先深研

满足下列一种或多种情况：
- 中性估值显示显著折价，且关键假设有一定证据支持；
- 悲观/中性情景差异较大，而有限的研究可能显著改变判断；
- 市场隐含预期与行业/公司基本面出现重大分歧；
- 有新的财报、订单、产能、政策、供需变化或治理事件可能改变估值；
- 用户明确指定优先研究。

升级必须说明研究问题、预期决策价值、所需资料/成本和停止条件。

### 6.3 降级或暂不跟踪

- 股价上涨或基本面变化使估值折价消失；
- 原有低估逻辑被新证据推翻；
- 关键盈利驱动恶化，且无法通过合理情景解释；
- 风险上升导致悲观情景的永久损失概率/幅度显著恶化；
- 研究成本高、关键问题长期无法验证，且新增研究价值有限；
- 相比其他候选，机会吸引力显著下降。

估值吸引力下降不必自动删除企业历史底稿。可将其转为“价格/业绩触发观察”或“低优先级”，并保留重新进入高优先级的触发条件。

### 6.4 退出常规观察池

- 触发阶段 1.1 的硬性排除条件，且无用户明确豁免；
- 核心投资逻辑被证伪或企业发生重大结构性变化，使旧估值模型失效；
- 研究对象不再符合用户设定范围；
- 用户明确要求移除。

退出时保留历史结论、退出原因、日期及重新进入条件，避免未来重复从头研究。

## 7. 复核触发条件

不设未经验证的固定复核频率作为唯一标准。出现以下事项应触发增量更新：
- 新财报、业绩预告、重大公告或审计意见变化；
- 关键产品价格、行业供需、产能、订单、资本开支或政策发生显著变化；
- 债务、现金流、股权稀释、质押、关联交易、诉讼或治理状况变化；
- 股价/市值变化使估值折价或隐含预期明显改变；
- 原有核心假设到达验证节点；
- 用户要求复核。

每次更新只重算受新信息影响的关键部分；若核心业务、会计口径或资本结构发生根本变化，则重新评估旧模型是否仍可用。

## 8. 已确认的投资决策政策

以下规则已由用户确认，是后续 SOP、估值方法、Agent 指令和测试案例的约束，不应在执行中自行更改：

1. **低估是排序主轴，但不能单看折价。** 以中性情景估值折价和市场隐含预期差异为主要排序依据，同时审查悲观情景、潜在永久性损失、财务/治理风险和估值可信度。
2. **分开管理三个维度。** 分别记录估值吸引力、进一步研究优先级和观察池状态，不将三者合并成一个标签。
3. **初版使用可解释的规则式排序。** 不设置未经真实案例测试的固定权重综合分或 0–100 精确评分；是否引入评分模型留待阶段 7 评估。
4. **基本面好但估值不便宜的企业不自动删除。** 可转入价格/业绩触发观察，记录重评条件和触发事件。
5. **研究优先级不等于交易优先级。** 技术面择时由用户依据自己的交易体系决定。
6. **采用三级估值深度。** 常规候选先做低成本估值分诊；仅对潜在低估、关键分歧或值得解决的疑点升级到校准估值；只有少数高价值候选进入深度估值。三级是资源投入层级，不是每家公司必须依次通过的关卡。
7. **初筛不要求完整的三套财务预测。** 应尽力形成与证据相匹配的粗粒度三情景区间或情景边界；如果无法可靠估值，必须标记“暂无法可靠估值”、说明关键缺口及其影响，不得编造数字。
8. **高影响分支由人类收敛。** 若多个研究方向会显著改变结论或工作量，先向用户展示选项、证据、预期决策价值和成本，再等待用户选择；不自行穷尽所有方向。
9. **每次估值吸引力判断都必须保存带时间戳的快照。** 使用 `Asia/Shanghai` 时区的 ISO 8601 分析时间戳，并记录市场数据时点、财报报告期/公告日期、估值方法/模型版本、关键假设、置信度和结论变化。新快照不得覆盖旧记录。
10. **成本与准确性通过分层投入平衡。** 初筛追求有效区分候选，不追求每家公司估值精确；后续研究只围绕可能改变估值、风险判断或观察池状态的关键问题展开。

## 9. 验收记录

阶段 1.2 的设计验收已于 2026-10-28 完成，理由如下：
- 观察池准入、优先深研、条件观察、降级、退出规则清楚；
- 每家公司有估值吸引力、研究优先级和置信度三个不同维度；
- 批量排序能解释为什么 A 排在 B 前面，且不只依赖一个估值倍数；
- 资料不足、特殊风险和无法可靠排序的情况有明确处理方式；
- 研究结论更新后能保留历史版本、原因和重新进入条件；
- 每次估值吸引力记录均有分析时间戳、市场数据时点、财报报告期和版本变化记录；
- 初筛采用轻量估值分诊，不要求所有候选建立详细三情景财务模型；升级到更深估值时须说明研究价值、问题范围和停止条件；
- 用户已明确表示接受本草案；正式规则 v1.0 据此发布。
